# 🌏 월드 매치 — 나랑 맞는 나라는?

지리(기후·정주 공간·에너지)와 일반사회(세금·복지, 일과 삶, 문화 다양성)를 섞은 **나라 궁합 밸런스게임**입니다.
12번의 A vs B 선택으로 나와 닮은 나라 조합(예: 🇳🇴 노르웨이 68% + 🇨🇦 캐나다 32%)을 보여 줍니다.

## 데이터
- 연평균 기온: Copernicus ERA5 (Our World in Data)
- 인구밀도·도시 인구 비율·외국 출생 인구 비율: 세계은행 (UN DESA)
- 조세부담률(사회보장 포함): UNU-WIDER (Our World in Data)
- 연간 노동시간: Penn World Table (Our World in Data)
- 재생에너지 발전 비중: Ember (Our World in Data)

결측값 일부는 추정값이며 게임 화면에 "추정"으로 표시됩니다.

## 매칭 방식
6개 축(1~5)으로 사용자와 국가를 표현하고, 중앙값(3) 기준 코사인 유사도로 비교합니다.
1·2위의 유사도 차이를 55~85% 범위의 비율로 바꿔 보여 줍니다. ⭐ 중요 문항은 2배로 계산합니다.
